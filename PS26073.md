**1\. Executive Summary**

SkyGuard AI is an intelligent, edge-integrated anomaly detection, root-cause diagnosis, explainable AI (XAI), and self-healing system engineered specifically for Automatic Weather Stations (AWS). By operating strictly on three core meteorological parameters—Temperature (°C), Atmospheric Pressure (hPa), and Relative Humidity (%)—the system identifies complex sensor malfunctions, transmission noise, calibration drift, and environmental anomalies in real time.

**3\. Deep-Dive Module Breakdown**

**Module 1: Ingestion & Physics-Informed Feature Engineering**

Raw stream data consists of isolated scalar values. To detect temporal anomalies and physics violations, the ingestion engine computes dynamic multivariate indicators:

- **Rate of Change (Deltas):** Calculates ΔT/Δt, ΔP/Δt, and ΔRH/Δt across 5-minute intervals to instantly capture unphysical spikes.
- **Rolling Std Dev (Variance):** Tracks variation over 5-minute and 1-hour sliding windows. A variance dropping to exactly zero indicates a stuck/frozen sensor.
- **Dew Point Approximation (Td):** Derived via Td ≈ T - ((100 - RH) / 5). If environmental conditions yield Td > T, a physical impossibility is flagged.

**Module 2: Tier 1 Real-Time Anomaly Detector**

The Tier 1 detector acts as a fast, low-overhead filter designed to operate on minimal computational power.

- **Algorithm:** Lightweight Isolation Forest / Quantized Autoencoder.
- **Function:** Measures path lengths to isolate points relative to normal historical bounds.
- **Output:** Binary flag (Normal vs. Anomaly) along with an Anomaly Confidence Score (0–100%).
- **Edge Feasibility:** Model logic is exported to standalone C++ code using m2cgen for direct execution on microcontrollers like ESP32 (< 2ms latency).

**Module 3: Tier 2 Root-Cause Classifier**

When an anomaly is flagged by Tier 1, the observation is routed to Tier 2 to categorize the fault mode.

- **Spike / Outlier:** Instantaneous, multi-sigma jump caused by power surges or transient telemetry noise.
- **Sensor Stuck / Frozen:** Zero rolling variance over consecutive timesteps caused by mechanical or firmware failure.
- **Calibration Drift:** Gradual linear desynchronization between parameters violating atmospheric correlations.
- **Communication Drop / Noise:** Null values, bit flips, or corrupted transmission frames.

**Module 4: Explainable AI (XAI) Engine**

To provide complete transparency for meteorologists and operators, SkyGuard integrates TreeSHAP (SHapley Additive exPlanations). It calculates the exact contribution of each parameter (and its rolling statistics) toward the anomaly flag, highlighting the primary corrupted feature.

**Module 5: Self-Healing Data Imputation Engine**

Instead of discarding corrupted records, SkyGuard maintains dataset continuity through an Iterative Multivariate Regressor. Corrupted parameter values are masked and predicted in real time based on uncorrupted joint variables and historical trends.

**Module 6 & 7: Predictive Maintenance & Visualization Dashboard**

Root-cause classifications map directly to actionable maintenance statuses (e.g., SCHEDULE_CALIBRATION, REPLACE_SENSOR, REBOOT_GATEWAY). The entire system streams into an interactive Streamlit UI showing live telemetry, alert histories, raw vs. corrected overlays, and XAI diagnostic breakdowns.
